⚡ Quadratic Solver

ax² + bx + c = 0  |  real roots (Δ ≥ 0, a > 0)
📐 How it works
→ Three prompt() dialogs for coefficients a, b, c.
→ Converts values using parseFloat().
→ Calculates Δ = b² – 4ac  →  x₁, x₂.
→ Shows results via alert() and also in console.
🧪 Test instructions
• Click the button below to start the solver.
• Open browser console (F12 → Console) to see console.log outputs.
• Try random values: a=1, b=-5, c=6 → roots 3 and 2.
• a=2, b=4, c=2 → double root -1.
• a=1, b=0, c=-9 → ±3.
💡 The script assumes a > 0 and Δ ≥ 0 (real roots).
But if you enter invalid data or violate assumptions → clear error message via alert & console.
